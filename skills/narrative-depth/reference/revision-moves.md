# Revision moves

Map each move to a StoryScope-aligned tell. Prefer structural change over synonym swaps. Do not rewrite toward "sounding human" for detector evasion—rewrite toward **specific craft goals** the user named.

## Theme and moralizing (Situatedness / Plot)

| If you see… | Try… |
|-------------|------|
| Narrator states the lesson | Delete the gloss; let a choice's cost imply theme |
| Dialogue as thesis debate | Give characters incompatible wants; let them talk past each other |
| Perfect thematic unity | Add a scene that contradicts the tidy moral |
| Vague literary allusions | Add one concrete named reference (work, place, brand) if world-appropriate |

## Plot and agency

| If you see… | Try… |
|-------------|------|
| No subplots | Add a subplot that **contrasts** the main theme (not a parallel sermon) |
| Protagonist always steers resolution | Let luck, institutions, or another character force a compromise |
| Ending = internal acceptance only | Require an external act with fallout, or leave a wound open |
| Morally clear hero | Force a choice where every option harms someone sympathetic |

## Time and revelation

| If you see… | Try… |
|-------------|------|
| Strict chronology | Open later; flash back once for recontextualization |
| Reveal telegraphed linearly | Withhold a fact the protagonist already knows; re-order disclosure |
| Flat middle | Insert a time jump that raises cost of delay |
| Epilogue that explains aftermath | Cut epilogue or replace with an unresolved image |

## Event escalation

| If you see… | Try… |
|-------------|------|
| Same emotional intensity throughout (Claude-like flatness) | Escalate **consequences** (irreversible loss, public exposure, deadline) not just adjectives |
| Obstacles that reset | Make failure permanent for a relationship or resource |
| Climax is a speech | Climax is an action that cannot be taken back |

## Character and emotion (Agent / Perspective)

| If you see… | Try… |
|-------------|------|
| Only bodily metaphors for feeling | Mix: one named emotion, one behavior, one withheld thought |
| Opening police-sketch description | Start mid-action or mid-dialogue; delay full description |
| Transparent interiority | Hide a motive; show a lie the narrator does not correct |
| Uniform voice | Let a secondary character narrate a short stretch, or shift register under stress |

## Setting and senses

| If you see… | Try… |
|-------------|------|
| Weather/room always mirrors mood | Make setting indifferent or ironic |
| Smell + texture + light every paragraph | Keep one sensory channel per beat |
| Tour of fine-grained space | Cut travelogue; keep the detail that enables a choice |

## Social texture

| If you see… | Try… |
|-------------|------|
| Isolated dyad only | Add a third party who spreads rumor or misreads events |
| Clean forgiveness | Leave reconciliation partial |
| Community as backdrop | Give the community a want that conflicts with the protagonist |

## Rewrite checklist (before delivering prose)

- [ ] No closing paragraph that names the theme or moral
- [ ] At least one morally uncomfortable choice (if length allows)
- [ ] Time or disclosure is not strictly neat (unless user wants linear)
- [ ] Stakes escalated once in concrete terms
- [ ] Subplot or loose thread exists or was consciously omitted with a reason
- [ ] Sensory/setting polish does not substitute for structure

## Tone for suggestions

Be plain and specific: cite line/scene, name the tell, propose one move. Avoid hype ("transform your writing"). Avoid slang. Credit StoryScope when explaining why a pattern matters.
